# AI 環保小創客｜六年級 AI 創作課程工具

指導學生用 Gemini、Suno、Canva 創作作品（環保海報、音樂 MV、網頁小程式），並完整記錄提示詞的迭代歷程。音樂創作可選環保主題或自由主題。

## 變更紀錄

### 2026-10-20　教師檢視器加班級篩選、下載歷程檔給學生還原
- 「全班總覽」新增班級篩選下拉選單（顯示各班人數）。總覽表、個別檢視的學生清單、成績 CSV 都只會包含選定的班級，CSV 檔名也會帶上班級。
- 新增「⬇️ 下載歷程檔（給學生還原）」：把目前篩選班級的每位學生各存成一個 `.json`，打包成一個 ZIP 下載。
- 「個別檢視」新增「⬇️ 下載歷程檔」，可以只下載單一學生的檔案。
- 歷程檔格式和學生自己「匯出備份檔」的格式相同。電腦有還原卡、資料消失時，學生在「歷程紀錄本 → 備份與送出 → 匯入備份檔」選這個檔案，就能找回已送出的紀錄。
- 限制：只能還原學生**最後一次送出**（或老師匯入）時的內容，送出之後才寫的紀錄無法找回。

### 2026-10-20　班級改下拉選單、座號統一兩位數
- 「我的資料」的班級改成下拉選單（預設 601～610），選項清單在 `assets/config.js` 的 `classes` 可自行增減。
- 座號一律存成兩位數：輸入 `2`、`02`、`２` 都會變成 `02`。
- 相容性：學生瀏覽器裡的舊資料會自動整理（例如「6年1班」→「601」、「2」→「02」）；教師檢視器匯入舊備份檔時也會一併整理，同一位學生不會被當成兩個人。
- `Code.gs` 也同步補兩位數。沒有重新部署 Apps Script 也能正常使用（學生端已先整理好），但重新部署後試算表的座號欄會更一致。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 單元入口：人機共創循環、提示詞五寶、迭代六招、10 節課程地圖、AI 使用約定 |
| `builder.html` | 提示詞積木產生器：海報／音樂創作（環保或自由主題、16 種 Suno 曲風模板）／網頁程式三種模式，複製時自動記錄 |
| `journal.html` | AI 創作歷程紀錄本：新增與編輯紀錄、版本時間軸、反思與自評、備份與送出 |
| `postplan.html` | 人工後製構想單：Canva 後製規劃、AI 與我的貢獻比例、AI 使用標示 |
| `teacher.html` | 教師檢視器：全班總覽、個別檢視與評分、雲端收件設定、成績 CSV 匯出 |
| `assets/config.js` | 雲端收件網址與班級密語（選填） |
| `apps-script/Code.gs` | Google 試算表收件程式（`teacher.html` 內也附了一份，修改時兩邊要一起改） |

## 資料收集流程

1. **學生端**：所有紀錄都存在學生電腦的瀏覽器（localStorage），不需要登入。
2. **送出給老師**（兩種方式擇一）：
   - **雲端收件（推薦）**：老師依照「教師檢視器 → 雲端收件設定」部署 Apps Script，再把「學生專用連結」貼到 Classroom。學生在歷程本按「送出」，資料就會寫進老師的 Google 試算表（學生總表、提示詞明細、後製構想三個工作表）。
   - **備份檔**：學生匯出 `.json` 檔並繳交到 Classroom，老師在檢視器一次匯入多個檔案。
3. **老師端**：在教師檢視器載入資料、評分，並匯出成績 CSV。

> 電腦教室如果有還原卡，請提醒學生每節課結束前「送出」或「匯出備份檔」。
