# 遊戲類型對照

先看內容性質選類型，再看年級調整難度。每種類型都沿用範本的「開始 → 遊戲 → 結果」三畫面、
計分、音效、彩帶與本機紀錄，只替換中間的遊戲畫面。

| 內容性質 | 推薦類型 | 年級 | 一局長度 |
|---|---|---|---|
| 選擇題、是非題 | 1. 答題闖關 | 全年級 | 5～10 題 |
| 快速辨認（字、數、圖） | 2. 打地鼠 | 低～中 | 30～60 秒 |
| 名詞 ↔ 解釋、中 ↔ 英 | 3. 配對連線 | 中～高 | 5～8 組 |
| 名詞 ↔ 解釋（加記憶） | 4. 記憶翻牌 | 全年級 | 6～8 對 |
| 分成兩類以上 | 5. 拖曳分類 | 全年級 | 8～12 張 |
| 步驟、時間先後、大小 | 6. 排序 | 中～高 | 4～6 項 |
| 圖形、地圖、結構 | 7. 拼圖／滑塊 | 中～高 | 3×3 |

---

## 1. 答題闖關（範本 `assets/starter.html`）

- 資料：`{ q, options: [...], ans: 索引, explain }`
- 每局從題庫抽 N 題並打散選項；答對 +10，連續答對加分（上限 +15）。
- 答錯：標出正確選項、顯示 `explain`，連擊歸零。
- 變化：加「生命值 ❤️×3」、闖關地圖（每 5 題一關）、Boss 題（最後一題雙倍分）。

## 2. 打地鼠

- 資料：`{ prompt: '找出偶數', good: ['2','8',...], bad: ['3','7',...] }`
- 3×3 洞口，每 0.8～1.5 秒隨機冒出一個項目，停留 1.2 秒；點到 `good` 加分、點到 `bad` 扣時間
  （不扣分，避免負分）。
- 速度隨時間緩慢上升；同一個洞不要連續出現兩次。
- 用 `pointerdown`（不是 `click`）判定，觸控反應較快。

## 3. 配對連線

- 資料：`pairs: [['光合作用', '植物利用陽光製造養分'], ...]`
- 左右兩欄各自打散。點左邊一項（高亮），再點右邊一項：對了兩項都變綠並鎖定；錯了輕晃並取消選取。
- 不用真的畫線也可以；要畫線就在兩個元素中心之間畫 SVG `<line>`，視窗 resize 時重算。

## 4. 記憶翻牌

- 資料同配對；每組拆成兩張牌（可以是「詞」與「解釋」，不一定兩張相同）。
- 狀態：`first`、`second`、`lock`。翻第二張後 `lock = true`，0.8 秒後判斷：
  相符則保持翻開，不符則翻回；然後解鎖。**鎖定期間忽略點擊**，否則會同時翻開三張。
- 翻牌動畫：`transform: rotateY(180deg)` 搭配 `backface-visibility: hidden`。
- 結算：步數越少星星越多（例如 ≤ 對數×1.5 為三星）。

## 5. 拖曳分類

- 資料：`bins: ['可回收', '一般垃圾']`、`items: [{ text: '寶特瓶', bin: 0 }, ...]`
- 用 Pointer Events 拖曳（見 `patterns.md` §1）；放開時用 `document.elementFromPoint`
  找出下方的籃子。放對：卡片縮小飛入籃子；放錯：彈回原位並顯示提示。
- **一定要有點選替代方案**：先點卡片、再點籃子也能分類（觸控不穩或鍵盤使用者）。
- 籃子要夠大（手機上每個至少 1/3 寬）。

## 6. 排序

- 資料：`items: ['播種', '發芽', '長葉', '開花', '結果']`（陣列順序就是正確答案）
- 打散後顯示；每項旁有 ⬆️⬇️ 按鈕（最可靠），進階可加拖曳。
- 按「檢查」後，位置正確的變綠、錯的變橘，讓學生再調整；不要一次就判定失敗。
- 打散後若剛好與正確順序相同，要重新打散。

## 7. 拼圖／滑塊

- 3×3 滑塊拼圖：**不要用完全隨機打散**，一半的排列無解。改成從完成狀態隨機合法移動 100 步。
- 圖片用自繪 SVG 或 emoji 組成，不要用課本照片。
- 提供「看原圖」按鈕與步數計。

## 難度調整建議

| 年級 | 調整 |
|---|---|
| 一～二年級 | 選項 2～3 個、字級加大、題目可加注音或語音（`speechSynthesis`）、不計時或 30 秒 |
| 三～四年級 | 選項 3～4 個、每題 20 秒、加連擊 |
| 五～六年級 | 選項 4 個、每題 15 秒、加生命值或闖關、開放挑戰模式 |

語音朗讀（選用）：

```js
function speak(text) {
  try {
    const u = new SpeechSynthesisUtterance(text);
    u.lang = 'zh-TW'; u.rate = 0.9;
    speechSynthesis.cancel(); speechSynthesis.speak(u);
  } catch (e) { /* 不支援就略過 */ }
}
```
